# Dynoplayer

A project that was ORIGINALLY planned to be written in C++ but since I need my final project, I wrote it in Java (Prob my worst decision made).
Anyways, this project RELIES on Youtube and (YT-DLP)[https://github.com/yt-dlp/yt-dlp] (I love them VERY much)

## Overview
This was developed with the intention of PERSONAL music playing without annoying ads or cut-offs that bothers me VERY much.
Therefore, as a student, I wrote this project.

## Core Dependencies:

JavaFX, the main UI carrier of this project [JavaFX(https://openjfx.io/), (Github)(https://github.com/openjdk/jfx/)

YT-DLP, ... Those who knows [YT-DLP](https://github.com/yt-dlp/yt-dlp) (BIGGEST HELPER)

## Installation

### Compilation from source:
```
git clone [https://github.com/YOUR_USERNAME/dynoplayer.git](https://github.com/YOUR_USERNAME/dynoplayer.git)
cd dynoplayer
mvn clean package
```

### Debian based System (Ubuntu, Pop, Zorin...) 
Download the .deb file!
